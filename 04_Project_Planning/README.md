# Phase 4 – Project Planning

## Project Title

Script-Controlled ACL – Restrict Record Access Based on Field Value

## 1. Project Objective

The objective of this project is to implement a Script-Controlled Access Control List (ACL) in ServiceNow to restrict or allow record access based on a selected field value.

## 2. Project Scope

The project includes:

- Identifying the required record access condition
- Selecting the field used for access control
- Designing the ACL logic
- Creating the ACL in ServiceNow
- Implementing the ACL script
- Testing authorized and unauthorized access
- Documenting the implementation and results

## 3. Project Activities

### Activity 1 – Requirement Analysis

Identify the security requirements and define the field-based access condition.

### Activity 2 – Project Design

Design the ACL structure and record access flow.

### Activity 3 – ACL Configuration

Create and configure the required ACL in ServiceNow.

### Activity 4 – Script Development

Develop the script to evaluate the configured field value and determine whether access should be allowed.

### Activity 5 – Testing

Test the ACL using different users and different record field values.

### Activity 6 – Documentation

Document the ACL configuration, script logic, test cases, and results.

### Activity 7 – Demonstration

Demonstrate how the ACL allows or restricts record access based on the configured condition.

## 4. Resources Required

- ServiceNow instance
- Administrator access
- Access Control List (ACL)
- Script editor
- Test users
- Test records

## 6. Risks and Mitigation

### Risk 1 – Incorrect ACL Configuration

**Mitigation:** Verify the ACL configuration and test different access scenarios.

### Risk 2 – Incorrect Script Logic

**Mitigation:** Test both allowed and denied access conditions.

### Risk 3 – Unauthorized Access

**Mitigation:** Test the ACL using users with different permissions and record values.

### Risk 4 – Unexpected Access Behavior

**Mitigation:** Review ACL evaluation and verify the configured conditions before deployment.

## 7. Project Deliverables

The project deliverables include:

- Requirement analysis document
- Project design document
- Project planning document
- Configured ACL
- ACL script
- Test cases
- Test results
- Project documentation
- Project demonstration

## 8. Success Criteria

The project will be considered successful when:

- The ACL is configured successfully.
- The selected field value is evaluated correctly.
- Authorized access is allowed.
- Unauthorized access is restricted.
- Test cases produce the expected results.
- The complete implementation is documented.

## 9. Conclusion

The Project Planning phase defines the activities, resources, risks, deliverables, and success criteria required to implement the Script-Controlled ACL solution in ServiceNow.
