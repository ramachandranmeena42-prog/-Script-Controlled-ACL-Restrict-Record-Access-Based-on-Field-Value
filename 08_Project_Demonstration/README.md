# Phase 8 – Project Demonstration

## Project Title

Script-Controlled ACL – Restrict Record Access Based on Field Value

## 1. Demonstration Objective

The objective of this demonstration is to show how the Script-Controlled ACL dynamically controls record access based on a configured field value.

## 2. Demonstration Environment

The demonstration is performed using:

- ServiceNow Developer Instance
- Configured ServiceNow Table
- Script-Controlled ACL
- Test Records
- Test Users

## 3. Demonstration Flow

The demonstration follows these steps:

```text
Open ServiceNow
      ↓
Open the configured table
      ↓
Select a test record
      ↓
ACL evaluates the record
      ↓
Field value is checked
      ↓
Access condition is evaluated
      ↓
Access Allowed / Access Denied
